# Heliora Diagnostic — Website V2 (Modern & Vibrant)

A static HTML/CSS/JavaScript website prepared for GitHub + Cloudflare Workers Static Assets / Cloudflare Pages.

## Files
- `index.html` — website content
- `assets/style.css` — responsive design
- `assets/main.js` — mobile menu
- `assets/heliora-original-logo.jpg` — user-provided original logo, unmodified
- `assets/heliora-emblem.jpg` — crop of the user-provided emblem for header
- `assets/heliora-wordmark.jpg` — crop of the user-provided wordmark (optional)

## Updating existing GitHub repository
Extract ZIP, open the `Heliora_Diagnostic_V2_GitHub` folder, upload its **contents** (not the enclosing folder) to the repository root. Replace `index.html`, `assets/style.css`, `assets/main.js` and add logo images. Commit. If Cloudflare is connected to GitHub, it will automatically redeploy.
